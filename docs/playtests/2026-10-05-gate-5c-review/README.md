# The review of gate 5c's playtests: what is in this folder

Read `report-2.md`. The rest is its record and its evidence.

| File | What it is |
|---|---|
| `report-2.md` | **The second edition (8 October 2026).** The whole review in an order that can be read cold, by subject, and brought up to date: what was found, what the owner ruled, what was built in the build folder `FreeSail-gate-m5c-c`, how it fared in play, and what is left. Its parts A to D, F, K, M and N are the quickest way in; part G is the detail, subject by subject. It carries the audit whole (parts M and N and appendix 1) |
| `handover-audit.md` | **The audit of the build (8 October).** A reviewer who had seen none of the work checked the build against the gate folder in the code and the tests: a ledger of every recommendation, ruling and brief item with its true state; the gate item by item, and what stops the naval cruise; what changed in the tree and the traps at a merge; where the claims and the code part company; advice by package. The second edition holds all of it; this is the original |
| `report.md` | **The first edition, kept as the record.** Written in three layers (5, 7 and 8 October) and not changed since the second edition was made from it. The briefs and the build's changes file cite its section numbers; appendix 2 of the second edition says where each part of it went |
| `evidence\` | The measurements, the readers' reports, the owner's material and the scripts. Its own `README.md` lists them |
| `drafts\` | The leaner consent brief as the owner approved it on 7 October, and the brief the two reviewers of 8 October worked from |

The same folder is kept in `FreeSail-gate-m5c` and in `FreeSail-gate-m5c-c`, file for file.
