# The pictures of the Indefatigable's testing report

Drawn by the game's own client in a headless browser. The sheets of the second report (commit
`5f27845`) come from the game's own world at seed 7. The Vanguard photographs and the Greenwich
sheets are not here: the first are in copyright and kept privately, the second are cited by
number in `docs/design/Build-Ships.md` §5.
