# Reference images

Pictures kept as visual references for vessels the library will build (proposal §12 item 11, revised 2026-09-26). Each is a public-domain work; the reasoning is stated so that it can be checked. The owner found them by image search; the build session traced their provenance on 2026-09-26.

The reference for the third vessel's sail plan and vibe. | Signed by a member of the Roux family of Marseille marine painters (Joseph 1725–1789, Ange-Joseph Antoine 1765–1835, and Antoine's sons, the last of whom died 1882).
