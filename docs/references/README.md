# Reference texts

Public-domain seamanship sources kept in the repository so that ship data, the evolution catalogue and the in-game reference library can cite them by chapter and section, and so that LLM officers can be pointed at the same passage a human would read.

All twenty-seven are optical-character-recognition (OCR) text dumps from Internet Archive scans. They are readable and searchable but not clean: expect occasional garbled words, stray characters from the scanner's language detection, and broken tables. Use them for research and citation, and check anything numeric against the page image (the PDF link in each item) before it becomes a game constant.

## How to cite in data files

Cite the work, chapter and sub-heading, not a line number in the OCR (line numbers change if the text is ever cleaned). Example, in an evolution file:

```
source: "Luce 1866, ch. XXIV Working to Windward, 'Tacking'"
```

`LuceChapterMap.md` in this folder maps the chapters to the game systems they feed.

`Tides.md` names the sources of the tide data (`data/tides/`, package 34): TICON's harmonic constants at eleven gauges (CC BY 4.0), SHOM's RAM for the French ports' datums (Licence Ouverte 2.0), the pilots' and Bowditch's streams by area, and the period's establishments as Whewell 1833 printed Dessiou's figures and Moore's rule of forty-eight minutes. `Charts.md` names every source of the chart data (`data/charts/`, package 32): the modern grids in the tiles with their licences, whose texts are kept under `licences/` (GEBCO's terms of use, CC BY 4.0, the Licence Ouverte 2.0, the OGL 3.0 and the Histolitt conditions), and the period charts and pilots the features and overrides were read from (Faden 1793, White 1835, Imray 1874, Mackenzie, Spence, Bellin, Serres), with what was taken from each. The pilots' OCR texts and the sheets' scans are cached outside the repository and never committed; the facts read from them are cited page by page in the data files.
