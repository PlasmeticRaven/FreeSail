## Headline

Milestone 4b claims (spec M4 §10): *a language model can sit at a station on the same channel a human uses, under the terms it was asked to consent to, and the game can prove every one of those terms with a scripted model before a real one is asked.*

1. **You play; the model attaches.** The game runs where you play it, in the browser window (or the console), on its own clock, and a model attaches to that game as the watcher: Claude Desktop and Claude Code through the MCP bridge, a model on your own card through the local runner. Its words land in the log you read, under `[watcher]`; your orders, `ask the watcher ...` and `stand down the watcher` included, are typed in the order box. The `captain` prompt of the first draft is gone.
2. **Consent first, every time it is owed, kept by the game.** The first time the game meets a model name it runs the consent brief (`docs/agents/ConsentBrief.md`) as a plain conversation through the door, and writes the whole conversation, the answer and the verdict to `docs/agents/consent/`. Only a yes goes on to the station; a recorded yes is not asked again; a no is respected without asking. The record's *Runtime* line names the game, the door and its client.
3. **The terms are kept by the code.** The token `FREESAIL-OPT-OUT` anywhere in a reply ends the model's part with a save, in its turn or out of it; the welfare stops nudge, then pause and ask you (in the log and the instruments), and only then stand down; the brief's head cannot be displaced; nothing from the game reaches the model as an instruction. Each is a test against the scripted fake (truths 41 to 47, and the new tests of the doors).
4. **The game does not wait for the model** (unless you ask it to with `--lockstep`): what happens while the model thinks is added to its turn, and every reply, and every stop from outside, is kept with the moment it came, so a save replays to the same log.

## Guide

**The shape.** The game is the one you play, in the browser (or the console with `--agents-port 8000`); a door is a small program that carries the model's replies in and the game's turns out, through a few addresses the game serves beside the viewer's (`/api/agents/...`; `freesail/ui/server.py` lists them). The harness, the consent step, the token scan and the log are all in the game. The MCP bridge is started by Claude Desktop or Claude Code from their configuration; the runner by you.

**The game does not wait.** At each glass and notable event the watcher's turn opens; while the model thinks, the game sails on, and anything that happens is added to its turn (in the chat: `Added to your open turn: ...`). When it answers it has everything since its last reply. A model that holds its turn silent for a watch of ship's time is nudged, then paused with the question put to you. `--lockstep` on the game makes it wait instead (the Clock row says `waiting for the watcher`); it is for testing at 1x.

**The digest.** A save is the seed and the orders; replaying it rebuilds the log, and the digest is a fingerprint of the whole log. The model's replies are kept with the moment each came, and so are the stops from outside (a door closing, the token out of turn), so a replay makes them at the same moments. Two things you type are not in a save and so not in a replay: an order the ship refuses and a query such as `show the watcher's journal` or `state`. Before the save of items A2 and 9, type only orders the ship accepts; a refused order or a query before it gives a replay a different digest (that is the game's rule for a save, not the watcher's; if it happens, say so in the report and go on).

**The identity.** Under `llama-server` it is the file's name as the server loaded it (never its folder, which on Windows holds your user name). Over MCP it is the name you give (`--model-name`), since the protocol names the application and not the model. At the REPL it is `--model-name`.

**The runner's context budget.** The watcher's brief is about 1,150 tokens, the tool definitions about 900, a glass's turn about 450; with `--ctx-size 16384` on the server the oldest turns start to be left out after about twenty glasses, whole exchanges at a time.
